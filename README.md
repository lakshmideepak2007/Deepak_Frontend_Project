## How to run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Safari, or Firefox.
3. Choose a section and open any experiment.
4. Use the **Home** and **Back to Programs** links on every experiment page.

## Notes
- Every listed frontend experiment is stored as a separate HTML file.
- Shared styling is in `assets/style.css`.
- Shared interaction helpers are in `assets/script.js`.
- The Node.js experiments from the source experiment list are not included because this deliverable is the **frontend HTML/CSS/JavaScript** portion of the assignment.
- Some browser APIs (such as geolocation) require browser permission and may behave differently when a page is opened directly from the local filesystem.
